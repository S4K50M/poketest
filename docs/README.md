# Documentation

[Project README](../README.md)

These guides describe the implemented **Momentum 4.0** campaign. Original design concepts are identified separately; historical arena mechanics are not the current game. Runtime code and data remain authoritative when tuning changes.

| Guide | Use it for |

| [Combat reference](combat.md) | Learn combos, defense, movement unlocks, and combat arts |
| [Boss encounters](boss-encounters.md) | Learn each guardian’s signature attacks, phase patterns, and escape routes |

| Guide | Use it for |
